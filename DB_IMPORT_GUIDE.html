How to import wh_db.sql into MySQL · Warehouse Information System (Nam Theun 2)

File you received: wh_db.sql — a MySQL dump (UTF-8 / utf8mb4, ~5 MB, 57 tables, full schema + data). It contains CREATE TABLE + INSERT statements only — no CREATE DATABASE — so you create the empty database first, then import into it.

2Step 1 — Create the database & user

Run these in the MySQL console (adjust the name / user / password to your standards):

CREATE DATABASE wh_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER 'wh_admin'@'localhost' IDENTIFIED BY 'CHANGE_ME_STRONG_PASSWORD';
GRANT ALL PRIVILEGES ON wh_db.* TO 'wh_admin'@'localhost';
FLUSH PRIVILEGES;

Please send the final database name, username, and password back to us — the application needs them in its .env config file.

3Step 2 — Import the data

Method A — Command line (recommended)

mysql -u wh_admin -p wh_db < wh_db.sql

It will prompt for the password, then import silently. No output = success.

Method B — phpMyAdmin

  1. Open phpMyAdmin → select the wh_db database on the left.
  2. Go to the Import tab.
  3. Click Choose File → select wh_db.sql.
  4. Make sure Format = SQL and Character set = utf-8.
  5. Click Go.
phpMyAdmin has an upload size limit (often 2 MB). This file is ~5 MB, so if the upload is rejected, either: raise upload_max_filesize / post_max_size in php.ini, or simply use Method A (command line), which has no such limit.

4Step 3 — Verify the import

USE wh_db;
SHOW TABLES;                       -- expect 57 tables
SELECT COUNT(*) FROM users;        -- expect 84
SELECT COUNT(*) FROM borrow_records;   -- expect 44
SELECT display_name FROM users LIMIT 5;  -- Lao names must show correctly (not ???)
If the Lao names display correctly (not as ??? or garbled), the character set is right and the import is complete. ✅

5Note — connecting the app later

The application is Laravel 12 (a PHP framework). After the database is imported, the app's .env file will point to this database:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=wh_db
DB_USERNAME=wh_admin
DB_PASSWORD=********

The app also requires PHP 8.2 or newer and its document root pointing to the project's /public folder — these are covered separately in the deployment guide.
