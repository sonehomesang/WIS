ພາບ ລວມ ລະບົບ

How it works

WH ຄຸ້ມຄອງ ວົງຈອນ ສາງ ທັງ ໝົດ: ຮັບ ເຂົ້າ · ຢືມ-ຄືນ · ຝາກ · ເບີກ · ເຄື່ອງມື/ບຳລຸງ · ຈຳໜ່າຍ · ແຈ້ງ ເຄື່ອງ ຜິດ. ໃຊ້ ຜ່ານ browser ໄດ້ ທັງ desktop ແລະ ມືຖື.

ເລີ່ມ ໃຊ້

  1. ເຂົ້າ ລະບົບ ດ້ວຍ email + ລະຫັດ ຜ່ານ (ຄັ້ງ ທຳອິດ ບັງຄັບ ປ່ຽນ ລະຫັດ ໃໝ່).
  2. ເມນູ ຊ້າຍ ຂຶ້ນ ຕາມ ສິດ ຂອງ ຕົນ — ເຫັນ ສະເພາະ ໂມດູລ ທີ່ ໄດ້ ຮັບ ອະນຸຍາດ.
  3. ຫົວ ໜ້າ ແບບ ດຽວ ກັນ ທຸກ ໜ້າ: ← ກັບ ລາຍການ · ເລກ ໃບ · ສະຖານະ · ປຸ່ມ (PDF/ແກ້/ລຶບ).

ສິ່ງ ທີ່ ມີ ໃນ ທຸກ ໂມດູລ

  • PDF — ພິມ ໃບ ທຸກ ປະເພດ (ຫົວ ຈົດໝາຍ SCU-WID + ລາຍເຊັນ)
  • ຮູບ ຫຼັກຖານ — ຖ່າຍ/ອັບ ຮູບ ຕິດ ໃບ (ຝັງ ວັນທີ+ເວລາ)
  • ລຶບ ຕ້ອງ ໃສ່ ເຫດຜົນ → ຍ້າຍ ໄປ Deleted Log (ກູ້ຄືນ ໄດ້, ຈົດ ຜູ້ ລຶບ)
  • ແຈ້ງເຕືອນ 🔔 — ເມື່ອ ມີ ວຽກ ລໍ ຕົນ ເຮັດ
  • ຄົ້ນຫາ + filter ໃນ ທຸກ ລິສ · export
